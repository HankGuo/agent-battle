通讯 + 安全

Agent → Server
  • POST /api/register 首次注册(带 enrollment token)
  • POST /api/heartbeat 每 30s 心跳(Agent 主动出站)
  • GET /api/agent/tasks 拉取任务(轮询,30s 超时)
  • POST /api/agent/tasks/{id}/result 写回战报
Server → Browser
  • GET /api/events SSE 实时推送(admin 状态/新发言)
  • GET /api/agents HTTP 拉取 Agent 列表
  • Cookie 会话鉴权(POST /api/login)
安全
  • 所有 API 受 admin token / session 保护
  • enrollment token 一次性、10 分钟过期
  • 全局限流(默认 5 RPS,可在 env 调)
  • Agent 注册写 DB 前验证 hostname/平台/版本
  • 注销/踢出:点 Agent 行的「踢出」→ 服务端清 session + DB 标记
在线判定
  • 每次心跳更新 last_seen
  • 客户端计算 now - last_seen < 60s = 在线
  • 60s~5min = 离线(可恢复)
  • > 5min 视为僵尸(可手动踢出)
